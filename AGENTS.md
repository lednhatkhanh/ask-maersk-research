## Agent skills

### Issue tracker

Issues are tracked as local Markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the five default canonical labels. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context layout. See `docs/agents/domain.md`.

### Presentation sync

When changing slide content, speaker notes, order, styling, or diagram assets under `slides/`, also update the existing editable Google Slides deck and verify both renderings before marking the task complete. Read `slides/GOOGLE_SLIDES.md` for the target, sync workflow, and saved helpers. An explicit local-only user request overrides this rule.
