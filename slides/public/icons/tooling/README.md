# Diagram activity icons

Generic activity icons from [Lucide](https://github.com/lucide-icons/lucide), downloaded 13 September 2026. See LICENSE. These are not Phoenix, Ragas or Promptfoo logos. Existing GCP icons in the parent folder identify Google services. SVG data is embedded into the editable draw.io exports. Regenerate both diagrams with `node slides/scripts/generate-tooling-diagrams.mjs` on macOS with draw.io Desktop.
